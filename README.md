A program that writes one line to `/output/entry.txt` — the funniest one-line out-of-office email reply — for [Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) on make.fun. A judge model reads the replies two at a time and keeps the one whose laugh lands hardest.

## The line

> Out of office: I'm on holiday, which means my inbox is now a museum — look, don't touch, and definitely don't expect a reply.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (125 characters, within the 1–160 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the out-of-office reply to `entry.txt`.
